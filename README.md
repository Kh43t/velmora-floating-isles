VELMORA — The Floating Isles: a program that paints a travel poster for a place that does not exist. A low sun sinks over a still sea while three green isles drift above the horizon, waterfalls spilling off their edges into the clouds below, under the name VELMORA set in a hand-drawn stroke typeface. Pure Node 22 standard library — no dependencies, no network, fully deterministic — it rasterizes a 1024×1024 poster and writes it to `/output/entry.png`.

## Run it

```sh
node main.ts
```
